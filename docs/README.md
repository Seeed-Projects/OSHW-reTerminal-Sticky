# reTerminal Sticky Repository Documentation

> **Status:** Planned. Official product tutorials are published on the [Seeed Studio Sticky Docs](https://www.seeedstudio.com/sticky/docs/en/device-guide/esp-basics/).

```text
docs/

├── faq.md               # Common build, flashing, and hardware troubleshooting notes
└── assets/              # Diagrams and photos referenced by repository READMEs
```
